# 副属和弦重配：目标与放置流程

## 默认操作

1. 在乐器轨的钢琴卷帘窗中选中目标音符。默认把所有选中音符合起来识别为一个目标和弦，即使它们位于不同时间。
2. 点击「生成副属和弦」，或使用原有的 Ctrl+K 快捷键。程序直接进入放置预览，不弹出参数窗口。
3. 预览只显示一组同时发声的柱式和弦：V7 为四个音，V7(♭9) 为五个音。它随鼠标在时间轴上横向移动，遵循当前吸附设置。左键放置；右键或 Esc 取消。
4. 原目标音符保留。放置操作作为一次撤销事务；移到当前 MIDI 片段范围外时预览变红，无法放置。

默认从全部选中音符识别一个目标和弦的根音。若在不同时间选中 C、E、G，目标仍是 C，只生成一组 G7（G–B–D–F）。一个选中音按其音高作为目标根音，转位和常见二音和弦也会识别。难以确认根音时可在设置中指定固定根音。

## 副属和弦模块的设置

模块内的「副属和弦设置」按钮展开内联选项。选项会保存到应用的界面状态，主窗口、浮动卷帘窗、右键菜单和快捷键使用同一份设置。

| 设置 | 默认 | 其他选择 |
| --- | --- | --- |
| 目标来源 | 选中音符合成一个和弦 | 每个选中音独立生成；后续和弦轨 / MIDI；固定目标根音 |
| 固定根音 | C，仅在选择固定目标根音时显示 | 12 个半音 |
| 和弦类型 | V7 | V7(♭9) |
| 声部连接 | 平滑连接 | 根音低音 |

「平滑连接」以选中音符的音域和声部位置为参考，寻找移动较小的属和弦排列。此设置决定生成音符的音高，放置预览只移动时间位置。

「每个选中音独立生成」和「后续和弦轨 / MIDI」是可选的逐音或按起点分组模式，可能生成多组和弦。选择固定根音时仍只生成一组柱式和弦。
