# 和声重配模块

在乐器轨的钢琴卷帘窗中选中一个或多个和弦，选择算法，再点击「重配所选和弦」。同一起点附近（容差 0.12 拍）的选中音符为一组；不同起点的和弦分别处理。每组至少要有三个不同的音高类别。模块会先列出每组的原和弦、目标和弦、根音方向及共有音数；不支持的组会显示原因。只有全部选中组都可重配时，应用按钮才会启用。重配直接改变所选音符的音高，保留原音符 ID、开始时间、长度、力度、静音状态和未选中音符。整个操作可以一次撤销或重做；任一组不符合算法条件时，所有组均不修改。

| 算法 | 行为 | 适用条件 |
| --- | --- | --- |
| 调内共同音替代 | 在当前位置生效的七声音阶中寻找另一音阶叠三度和弦，至少保留原和弦的两个音高类别；原和弦有七度时优先保持四音结构，在候选中选声部移动较小者 | 七声音阶；至少三个不同音高类别 |
| 三全音替代 | 将属七根音移动三全音，保留原三度与小七度作为替代和弦的导向音；无五度的三音壳可保持三声部，已选九度等色彩音可转成替代和弦的变化音 | 必须能识别根音，并包含该根音的大三度和小七度；大七和弦不适用 |
| 平行调式借用 | 根据当前调式的主音大/小三度选择平行自然小调或大调；在原和弦同一根音上按目标音阶叠三度生成和弦，七和弦的七度也取自目标音阶。可生成减三和弦等实际的借用和弦 | 当前调式为明确大/小三度的七声音阶，原根音存在于目标平行调式，且目标和弦确实不同 |
| 色彩三度关系 | 在根音上下大三度或小三度的候选中保留原大/小三和弦性质及所选七度类型；要求至少一个共有音与至少一个调外音，选择声部移动较小者 | 明确的大三或小三和弦，包含纯五度 |
| 功能替代 | 在当前七声调式中按明确的功能关系互换主和弦与六级、四级与二级；原和弦是七和弦时保持四音结构 | 原和弦包含完整的调内三和弦，调式主和弦有明确大/小三度 |
| 后门属和弦 | 将大调五级属七替换为降七级属七，保留两个共有音并寻找移动较小的声部排列 | 当前调式以大三和弦为主和弦；选四声部以上的 V7 |

声部排列根据所选音符原音域寻找，始终保持 MIDI 音高在 0–127 之内。当前调式以该组音符所在时间的调式轨或全局调式为准。

「调式色彩 → 应用所选调式」会同时更新工程主音、音阶和选中的调式轨事件，作为一次操作进入撤回历史；撤回与重做会一起恢复这些值。

## 八度快捷键

钢琴卷帘窗中选择音符后，`Shift+↑` 上移一个八度，`Shift+↓` 下移一个八度。两项命令位于「首选项 → 快捷键 → 编辑」，可自行修改。若任一选中音符超出 MIDI 音域，整次移动取消，以免改变和弦音程；操作支持撤销。

「副属和弦」是独立模块，仍保留其生成、鼠标预览及放置流程。旋律生成柱式和弦属于后续模块。

## 模块分工

「和声重配」集中处理原位置上的单和弦替代。调内共同音、三全音、色彩三度、功能替代和后门属和弦使用相同的选区与预览流程；同主音借用保留一键入口，需要指定目标调式时使用独立的「调式借用」模块。需要生成新和弦并由鼠标选择时间位置的副属和弦继续保持独立。
