# 通道推子初步优化

乐器与音源模块、音频轨模块的音量与声像控件统一使用窄轨道、刻度、中心/0 dB 标记及带高光的推子帽。音量框显示 dB（静音显示 −∞ dB），声像框显示 L/C/R 百分位置；双击推子可分别回到 0 dB、中央。

现阶段仍以工程文件中的线性增益 `0..2` 和声像位置 `-1..1` 为保存值。音量推子的显示位置加入初步的非线性分布，行程中点约为 −18 dB，便于细调较低音量。声像混音采用中心电平不变的等功率增益：左声道 `sqrt(1 - pan)`、右声道 `sqrt(1 + pan)`。这消除了此前左右端点的 6 dB 增益抬升，同时不改变居中轨道的既有电平。

电平表、响度测量、音量自动化曲线和更精细的推子刻度律尚未纳入本次改动，可在后续专项优化中统一处理。
