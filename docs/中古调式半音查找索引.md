# 中古调式半音查找索引（钢琴卷帘窗专用）

> **定位**：本文件为「音符属性检查器」的**直查数据源**，针对钢琴卷帘窗（MIDI 输入）场景设计。
> 输入为纯 MIDI 编号，无音名拼写信息，因此以**半音差**为唯一查找键，彻底绕开同音异名问题。
>
> **使用方法**
> 1. 计算半音差：`semitone = (音符MIDI - 根音MIDI) mod 12`
> 2. 在当前背景调式的表中，查找对应半音差的行
> 3. 直接返回该行所有字段
>
> **列含义**
> - **半音**：音符与调式根音的半音差（0-11）
> - **级数**：该音在当前调式中的级数名称（★ = 调式特征音）
> - **类型**：`调内` = 调式自然音级 / `变化（路径）` = 元数据收录的常见变化音 / `调外` = Fallback 纯声学
> - **功能与倾向**：浓缩的结构角色 + 旋律动态方向
> - **维度**：变化音的适用场景标签；调外音的最近借用来源
>
> **配套文件**：完整四维属性详见 [中古调式功能元数据_v2.md](中古调式功能元数据_v2.md)

## 音名-半音编号速查

```
C = 0    C♯/D♭ = 1    D = 2     D♯/E♭ = 3
E = 4    F = 5        F♯/G♭ = 6  G = 7
G♯/A♭ = 8  A = 9     A♯/B♭ = 10  B = 11
```

**计算示例**：背景调式 D Aeolian，选中音符 C♯
→ `semitone = (1 - 2 + 12) mod 12 = 11` → 查 Aeolian 表第 11 行

## 实现参考

```python
# 音名 → pitch class 映射
PITCH_CLASS = {
    'C': 0, 'C#': 1, 'Db': 1, 'D': 2, 'D#': 3, 'Eb': 3,
    'E': 4, 'F': 5, 'F#': 6, 'Gb': 6, 'G': 7, 'G#': 8,
    'Ab': 8, 'A': 9, 'A#': 10, 'Bb': 10, 'B': 11
}

def check_note(root_midi: int, note_midi: int, mode: str) -> dict:
    """
    音符属性检查器主入口
    
    Args:
        root_midi: 背景调式根音的 MIDI 编号（如 D = 62）
        note_midi: 选中音符的 MIDI 编号（如 C# = 73）
        mode: 调式名（如 "Aeolian"）
    
    Returns:
        该音符在当前调式中的完整功能属性
    """
    semitone = (note_midi - root_midi) % 12
    return MODE_INDEX[mode][semitone]

# 示例
result = check_note(root_midi=62, note_midi=73, mode="Aeolian")
# → semitone = 11
# → { 级数: "♮7", 类型: "变化（♭7→♮7）",
#      功能: "和声小调导音；极强↑半音→1",
#      维度: "〔终止·线性〕" }
```
