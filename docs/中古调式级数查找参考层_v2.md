# 中古调式级数查找参考层 v2

> **定位**：本文件是分析框架的 **Fallback 参考层**，与《中古调式功能元数据 v2》配合使用。
> 当目标音级在调式元数据中**无精确条目**时，按本文件的查找链逐级降级处理。
>
> **v2 变更日志**
> 1. 新增 **Level 0：等音归一化**，解决异名同音的输入标准化问题
> 2. **Level 2 匹配逻辑修正**：以变化后的**目标音级**为检索键（非变化前的原级）
> 3. **Level 3 通用半音表**：剥离大调/Ionian 偏见，改为条件式中立描述
> 4. 半音 6（三全音）**拆分为 ♯4 与 ♭5 两行**，分离方向向量
> 5. 新增三个级别的**完整 JSON 输出示例**
> 6. 新增**等音归一化映射表**

## 一、四级查找链（决策流程）

```
输入：[调式名] × [原始音级符号]
         │
         ▼
【Level 0】等音归一化（预处理）
  将输入音级归一化为标准拼写 + 半音数 + 方向提示
  详见「等音归一化规则」
         │
         ▼
  归一化后：[调式名] × [标准音级] × [半音数] × [方向提示]
         │
         ▼
【Level 1】精确匹配——调式调内音表
  以标准音级检索《中古调式功能元数据 v2》对应调式的基本音级行
  ├─ 命中 → 返回完整四维属性 + 适用维度
  │          标签：[调内音]
  └─ 未命中 ↓
         │
         ▼
【Level 2】变化音匹配——调式变化音表（以目标音级为键）
  以标准音级检索《中古调式功能元数据 v2》对应调式的 ↗变 行
  ══════════════════════════════════════════════════════
  ‖ 匹配规则：以变化后的【目标音级】为检索键              ‖
  ‖ 例：输入 Dorian + ♭6                               ‖
  ‖ → 匹配 ↗变 「6 → ♭6」行（目标 = ♭6，命中）          ‖
  ══════════════════════════════════════════════════════
  ├─ 命中 → 返回变化音属性 + 变化路径 + 适用维度标签
  │          标签：[调式变化音]
  └─ 未命中 ↓
         │
         ▼
【Level 3】通用 Fallback——纯声学半音参考表（见下）
  仅凭音级与主音的音程关系返回声学属性（中立，不含调式偏见）
  标签：[调外音 · 非调式原生] + 建议标注具体来源调式（见附录）
```

> **重要提示**
> - Level 2 使用变化后的**目标音级**而非变化前的原级进行匹配。
> - Level 3 结果为**纯声学属性**，不含任何特定调式的和弦尺度理论（CST）判定。
>   分析时应在输出中附加来源说明，例如："该音在 Dorian 中为调外音，声学上为小六度，
>   最近借用来源为 Aeolian 或 Phrygian 的 ♭6 级。"

## 二、Level 0：等音归一化规则

> 将用户输入的任意音级符号归一化为标准拼写，同时保留方向信息。

### 归一化映射表

| 半音数 | 标准拼写（默认） | 常见异名输入 | 方向提示 | 归一化说明 |
|--------|----------------|------------|---------|-----------|
| 0 | **1** | — | — | 主音，无异名 |
| 1 | **♭2** | ♯1 | ♭2 = 下行挤压；♯1 = 上行副导音 | 默认归为 ♭2；若上下文明确为上行半音趋近，保留 ♯1 并标注 |
| 2 | **2** | ♭♭3 | — | 极罕见异名，直接归为 2 |
| 3 | **♭3** | ♯2 | ♭3 = 小三度自然音；♯2 = 增二度上行 | 默认归为 ♭3；增六和弦语境中保留 ♯2 |
| 4 | **3** | ♭4 | — | ♭4 极罕见，归为 3 |
| 5 | **4** | ♯3 | — | ♯3 极罕见，归为 4 |
| 6 | **♯4** 或 **♭5** | — | **♯4 = 上行推向 5**；**♭5 = 下行坍向 4/1** | **不归一化**，保留方向拼写；查找表中拆分为两条 |
| 7 | **5** | ♭♭6 | — | 极罕见异名，直接归为 5 |
| 8 | **♭6** | ♯5 | ♭6 = 下行/小调自然音；♯5 = 增五度上行 | 默认归为 ♭6；Lydian Augmented 语境中保留 ♯5 |
| 9 | **6** | ♭♭7 | — | 极罕见异名，直接归为 6 |
| 10 | **♭7** | ♯6 | ♭7 = 次主音自然音；♯6 = 增六度上行 | 默认归为 ♭7；增六和弦语境中保留 ♯6 |
| 11 | **7** | ♭♭1(8) | — | 极罕见，归为 7 |

### 重升/重降处理

```
输入包含 ♯♯ 或 ♭♭ → 解析为对应的等效单升降或还原音
示例：♯♯4 → 5（半音数 7）
      ♭♭7 → 6（半音数 9）
      ♯♯1 → 2（半音数 2）
```

### 归一化输出格式

```json
{
  "raw_input": "♯1",
  "normalized_degree": "♭2",
  "semitone": 1,
  "direction_hint": "上行（原始拼写为升号，保留上行副导音语义）",
  "enharmonic_note": "原始输入 ♯1 已归一化为 ♭2，方向信息已保存"
}
```

## 四、稳定性速查分级

```
【S1 极稳定】  1（0）、5（7）
【S2 较稳定】  ♭3（3）、3（4）、6（9）
【S3 弱稳定】  2（2）、4（5）、♭7（10）
【S4 不稳定】  7（11）、♭6（8）
【S5 极不稳定】♭2（1）、♯4（6）、♭5（6）
```

> **使用注意**：S3 中的 4（纯四度）在小三度调式中实际稳定性可达 S2 水准；
> S4 中的 ♭6（小六度）在 Aeolian / Phrygian 中为调内音，实际稳定性高于此处声学评级。
> 本分级仅反映**脱离调式语境的纯声学稳定性**，具体调式中应以 Level 1/2 的判定为准。

## 七、框架集成建议

### 数据流示意

```
[输入：调式 + 原始音级]
        │
        ├──► Level 0：等音归一化
        │       输出：标准音级 + 半音数 + 方向提示
        │
        ├──► Level 1：查 元数据_v2 基本音级行（标准音级为键）
        │       命中 → 输出 [调内音] 属性
        │
        ├──► Level 2：查 元数据_v2 ↗变 行（变化后目标音级为键）
        │       命中 → 输出 [调式变化音] 属性 + 适用维度
        │
        └──► Level 3：查 本文件（通用半音参考表）
                        │
                        ├── 输出纯声学属性（稳定性 / 声学色彩 / 旋律重力）
                        ├── 附加标签：[调外音 · 非调式原生]
                        ├── 附加建议：查「调外音来源速查附录」定位借用语境
                        └── 附加：方向提示（来自 Level 0）
```

### 检索伪代码

```python
def lookup_mode_degree(mode: str, raw_degree: str) -> dict:
    """四级查找链主入口"""
    
    # Level 0：等音归一化
    normalized = enharmonic_normalize(raw_degree)
    std_degree = normalized["normalized_degree"]
    semitone = normalized["semitone"]
    direction = normalized["direction_hint"]
    
    # Level 1：调内音精确匹配
    diatonic = metadata_v2[mode]["diatonic"]
    if std_degree in diatonic:
        return {
            "lookup_level": 1,
            "tag": "调内音",
            **diatonic[std_degree]
        }
    
    # Level 2：变化音匹配（以目标音级为键）
    alterations = metadata_v2[mode]["alterations"]
    # 构建目标音级索引：{target_degree: alteration_entry}
    alt_target_index = {
        alt["target"]: alt for alt in alterations
    }
    if std_degree in alt_target_index:
        return {
            "lookup_level": 2,
            "tag": "调式变化音",
            **alt_target_index[std_degree]
        }
    
    # Level 3：通用声学 Fallback
    acoustic = semitone_reference[semitone]
    # 若半音 6，根据方向拼写选择 ♯4 或 ♭5 行
    if semitone == 6:
        acoustic = tritone_split[std_degree]  # "♯4" 或 "♭5"
    
    borrow_sources = borrow_appendix.get(std_degree, [])
    
    return {
        "lookup_level": 3,
        "tag": "调外音 · 非调式原生",
        "direction_hint": direction,
        "borrow_source": borrow_sources,
        **acoustic
    }
```
